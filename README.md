# Personality-Based Campus Club Recommendation System

## Overview

A Python-based interactive program that helps students explore campus activities and find suitable clubs based on their interests and personality preferences.

Users complete a short personality questionnaire, and the program generates a personality profile and recommends campus activities accordingly.

## Key Features

- **Interest Selection:** Choose preferred activity categories, including sports, academics, arts, volunteering, and social activities.
- **Personality Assessment:** Answer 12 questions to evaluate four preference dimensions.
- **Personalized Recommendations:** Receive a personality type and relevant campus club recommendations.
- **Recommendation Explanation:** View the reasoning behind the recommendations and a breakdown of assessment scores.
- **Interactive Terminal Interface:** Complete the assessment through a command-line interaction.

## Technical Implementation

- **Language:** Python
- **Core Concepts:** Dictionaries, lists, loops, conditional logic, user input validation, and score-based classification.
- **Recommendation Logic:** A rule-based scoring system maps users' answers to personality profiles and campus activity recommendations.

## Project Background

Developed as a team project for a university course on problem solving and computational thinking.

The project explores how user preferences can be translated into structured profiles and used to provide personalized recommendations.

## Future Improvements

- Improve the assessment and recommendation logic through user testing.
